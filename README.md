# Server Health Dashboard 
Monitor de recursos del sistema en tiempo real. 
Desarrollado con Python (FastAPI) para el backend y HTML/JS (Chart.js) para el frontend.

## Cómo ejecutarlo
1. Instala las dependencias: `pip install fastapi uvicorn psutil`
2. Ejecuta la API: `python -m uvicorn main:app --reload`
3. Abre el archivo `index.html` en tu navegador.
